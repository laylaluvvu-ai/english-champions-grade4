# English Champions — رابع ابتدائي

واجهة GitHub Pages لمنهج Top Goal 1، الفصل الأول. ست جولات و30 سؤالًا.

إعدادات مشروع Firebase مضبوطة. دخول الطالبة بالاسم والرمز، ودخول المعلمة برمز حساب Firebase فقط. تفويض المعلمة يعتمد على وثيقة teachers/{UID} المحمية بقواعد Firestore؛ البريد في إعدادات الواجهة ليس سرًا، ولا توجد كلمة مرور مخزنة في المستودع.

قبل الاستخدام: نشر قواعد Firestore والفهرس من الحزمة الخاصة، إضافة نطاق Pages إلى Authorized domains، ثم استيراد مفاتيح الإجابات عبر setup.html بعد تفويض المعلمة. لا تنشري مجلد private أو answer-keys.json في هذا المستودع.

لتفعيل الرابط: Settings → Pages → Deploy from a branch → main → /(root).
